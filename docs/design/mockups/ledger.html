Each independent-expenditure dollar in this race is weighted by the disclosed share of the spender's own receipts, walked back through committee-to-committee transfers to a named individual, business or union on an FEC filing. The remainder stopped at an organization whose own funding is not on file (501(c)(4), LLC, trust). Nothing is inferable in V0.

Full method, caveats and what "disclosed" does not mean

Committees whose receipts lie outside the loaded 2,000-committee neighborhood count as disclosed without being walked. Form 5 filers ($532,391) count as dark. Super PAC spending is itself disclosed; this score is about the layer behind the spender, not the spender. Organizations are classified by name; no IRS lookup.

What the flags mean
⚑ dark dead-end
Backward walk reaches an organization with no donor-disclosure obligation (501(c)(4), LLC, trust).

≈90%+ of itemized receipts came from one counterparty.
⚑ shared address
Same street address, registered agent or treasurer as other committees in this race.
Annotations (mockup only — not part of the UI)
  1. 1Four race-level KPIs move into the hero, right-aligned, one type size (24px). Traceability joins them so the page's key number is above the fold on a projector.
  2. 2Candidate panels: one FEC link per block instead of one per line (11 → 3 links). Sub-lines are indented and greyed; totals carry a hairline rule. Party is a text mark, not a red/blue box, so it stops competing with the dark/disclosed palette.
  3. 3Campaign vs outside uses a dedicated second hue (violet) instead of grey, so "outside" is no longer visually "unknown". Legend carries the numbers.
  4. 4Traceability: one 44px number, a 14px stacked bar with a hatched dark segment (colour-blind safe), the three amounts under it. The 180-word method paragraph is folded behind a disclosure.
  5. 5Spenders table: traceability gets a 44px inline bar so the column can be scanned; flags shrink to 3 short labels with tooltips; type folds into a chip next to the name; row IDs in mono. On mobile the table collapses into cards (no horizontal scroll).
