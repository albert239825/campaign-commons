Campaign Commons02

The user

A voter in Pennsylvania saw the ad.
The screen said “Paid for by WinSenate PAC.”

What it takes to answer “who is that?” today:

  1. fec.gov — Schedule E CSV, committee IDs, no chain
  2. Google ad library — 1,849 PA ads, legal names, no “paid for by”
  3. OpenSecrets — summaries, no filing rows
  4. senate.gov — roll-call XML for what the candidate actually did
  5. congress.gov, Wayback — bills, deleted issue pages

Six sites. Zero links between them. Each one a dead end.

Disclosure without navigability
is obfuscation.

Best use of AI

The model never produces a number.

Routes

Question → one of four allowlisted graph operations + subjects. Fixed Cypher runs; the model never writes a query.

Classifies

Ad transcript → issue. Org self-description → focus. Candidate statement → stance. Each with a verified quote and source.

Summarizes only from facts

Numeric-claim guards. A summary that can't be grounded in the computed facts is withheld.

Machine summary · not part of the record review_status: pending accepted → verified

model · prompt version · response ID · citations · confidence · reviewer. Pending rows never enter a headline.
